1.3.4. 更新蓝牙地址说明

1.3.4.1. 选项说明

  1. 全部更新选项是指更新蓝牙地址时会将蓝牙地址6个字节都更新，低位更新是指只更新蓝牙地址低3个字节。

  2. 自增更新选项是指更新蓝牙地址后蓝牙地址会自动加1，不用手动修改蓝牙地址。（选择蓝牙地址文件后无效）

  3. 选择蓝牙地址文件后会按蓝牙地址文件内蓝牙地址顺序自动更新蓝牙地址。（自增更新选项无效）

1.3.4.2. 蓝牙地址文件说明

蓝牙地址文件第一行第一列需要是”蓝牙地址”或”MACADDRESS”，第一行第二列需要是”是否已使用”或”USED”。
