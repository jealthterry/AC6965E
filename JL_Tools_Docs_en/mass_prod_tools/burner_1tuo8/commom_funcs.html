2.20. Other Common Features: Configuration and Use

2.20.1. Programming AC521X video chips

When programming AC521X chips with the 1-to-8 programmer, if the chip's KEY has not been programmed before, the following conditions must be met:

  • [1] The four pins USB_VCC, USB_DM, USB_DP and GND must be connected;

  • [2] If the chip is blank and no KEY file has been programmed, a 4.5V voltage must be supplied to the chip's PA13 pin during programming;

  • [3] If the chip is not blank and a KEY file has already been programmed, there is no need to supply power to the PA13 pin during programming; you can upgrade the chip firmware directly through the USB connection;

Programming the KEY of a video chip for the first time generally requires an additional external voltage on a specific pin. Therefore, if you need to program a chip's KEY, it is usually more convenient to use the 1-to-2 programmer. The 1-to-8 programmer is generally used to upgrade the firmware of chips whose KEY file has already been programmed.

2.20.2. Programming AC791N/AC531N chips

Blank AC791N/AC531N chips must first be programmed with the 1-to-2 programmer. You cannot program a FW file with a KEY directly with the 1-to-8 programmer, because the conditions for programming the KEY of this chip model are special. The 1-to-8 programmer currently blocks blank-chip programming of AC791N/AC531N and supports only reprogramming of the flash data.

  • [1] To program a FW file with a KEY into a blank chip, you must use the 1-to-2 programmer.

  • [2] For reprogramming, where only the FLASH data is upgraded, you can use the 1-to-8 programmer, but you must at least confirm on one device that it powers on.

2.20.3. Programming AC792N chips

Blank AC792N chips can be programmed directly with either the 1-to-2 or the 1-to-8 programmer. The programming connections are usually VBAT, USB_DM, USB_DP and GND.
