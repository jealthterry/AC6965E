3.5. Wired Upgrade of Bluetooth Devices

3.5.1. Online wired UART upgrade

  • Requirements

    1. Test boxes with hardware version v2.2 or later and firmware version v2.1.7 or later support the TWS pair test interface.

    2. For TWS devices whose LDO pin supports UART communication (shared with the UART IO) and whose LDOIN capacitor is smaller than 103, the test box can be connected to the TWS devices through the test box UART adapter board.

  • Supported features

    1. Supports dual-channel upgrade in TF card upgrade mode (TF card inserted into the test box)

    2. Supports selecting the left or right earbud for upgrade in test box PC mode

    3. Supports a configurable UART upgrade baud rate (10K-2000K) (V1.2.4 adds support for 10K\~100K)

    4. Supports staying on the upgrade screen after the upgrade completes, or upgrading automatically

Note

10K~100K can be configured only if supported by the corresponding SDK; 100K~500K are the commonly used baud rate options

  • Mutual exclusion with other test box functions

    1. "TWS pair UART upgrade enable" (对耳串口升级使能) and "TWS pair test enable" (对耳测试使能) cannot be used at the same time; at least one of them must be turned off in the configuration.

    2. Before upgrading the test box firmware, turn off "TWS pair UART upgrade enable" (对耳串口升级使能) first; otherwise, the test box firmware cannot be updated.

    3. When "TWS pair UART upgrade enable" (对耳串口升级使能) is turned on, the original Bluetooth wireless upgrade functions (including card upgrade and PC interface upgrade) cannot be used.

  • Usage

    1. Turn on "TWS pair UART upgrade enable" (对耳串口升级使能) in the PC tool interface;

      and set a suitable baud rate (default: 500,000);

      "Upgrade flow" (升级流程) and "Upgrade to RAM enable" (升级到RAM使能) are 0 by default;

      use "Stay after UART upgrade" (串口升级后停留) to choose whether to stay on the upgrade screen;

      Click "Save settings to test box" (保存设置到测试盒), then restart the test box to enter UART upgrade mode.

    2. UART upgrade through the PC interface

      Switch the PC interface to the "Device upgrade" (样机升级) page. By default, the left and right earbud devices "earphone-L" and "earphone-R" are shown. When the left and right earbuds are online, the Bluetooth addresses of the corresponding devices are shown; the Bluetooth address of an offline device is 0 or 1.

Note

If the upgrade is interrupted, you can still select the left or right earbud for upgrade even though the earphone is offline (address 0 or 1).

  1. UART upgrade by inserting a TF card

Put the upgrade file (update.ufw) in the root directory of the TF card and insert the card into the test box. The test box starts the upgrade as soon as it detects that an earphone is online; the left and right earbuds can be upgraded over UART at the same time.

3.5.2. Offline wired UART upgrade (using a TF card)

If you do not want to connect to a PC with a USB data cable to perform an online wired upgrade with the .ufw file,

you can follow the section "Batch wired upgrade of Bluetooth devices": insert a TF card containing the upgrade file (such as *.bfu or *.ufw) into the TF card slot on the left side of the test box to upgrade the Bluetooth device firmware.
