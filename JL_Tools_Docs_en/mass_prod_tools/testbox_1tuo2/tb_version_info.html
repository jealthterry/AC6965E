3.17. Version Information

Version

Date

Remarks

V132

2024-06-12

1. Supports AW31N upgrade
2. Added an option for whether to stay on the upgrade screen after a UART upgrade
3. Supports the new UART upgrade process
4. Optimized the triple synchronization process
5. Added a pairing error prompt tone in storage mode
6. Optimized the USB PC tool - UART passthrough mode
7. Added Bluetooth name verification to verification mode
8. Optimized the verification mode display
9. Optimized continuous UART upgrades
10. Added an option for whether to show the remote address after the storage mode pairing check fails

V131

2023-12-01

1. Supports AC706N wireless mic upgrade/frequency offset test
2. Compatible with the AC704N/AC705N/AC708N/JL708N/JL703N/JL700N series
3. Improved the interference resistance of BLE upgrade
4. Fixed a prompt tone issue with custom UART commands
5. UART TWS pairing supports verification mode
6. Supports the USB PC tool - UART passthrough mode
7. Supports pushing code over UART to AC704N RAM and running it
8. Supports configuring the device to power off or reset after the test box Bluetooth is disconnected
9. Supports production test log output mode
10. Added wireless mic test mode configuration prompts
11. Supports the new UART upgrade process

V130

2023-05-04

1. BLE master mode supports a configurable Bluetooth name
2. Supports 2.3/2.5G wireless mic upgrade
3. Supports maximum/minimum limits for ANC gain adjustment
4. Supports AC703N upgrade
5. Fixed an issue in v129 where pairing succeeded after a TWS pairing code mismatch error
6. Supports the TWS pairing and test function
7. Optimized the prompt tones for entering DUT mode and storage mode
8. Fixed SDK info and checksum display issues
9. Improved BLE upgrade speed

V129

2023-02-06

1. Supports ANC calibration
2. Supports spatial audio (gyroscope) calibration
3. Fixed an issue where TWS pairing could occasionally ignore pairing code differences when the out-of-case power-off setting was off
4. Supports AC702N upgrade
5. Supports showing the battery percentage in battery verification mode

V128

2022-08-18

1. Improved the test box documentation
2. Fixed a checksum display issue
3. Fixed occasional verification failures when upgrading watches with external flash
4. Supports upgrading wireless mic 2t1 and duplex configurations
5. Supports triple synchronization and verification (requires SDK support)
6. Supports BLE custom data display in the PC tool

V127

2022-04-11

1. Supports broadcast-type wireless upgrade and testing of wireless mic 1t1
2. Added a TWS pairing check function for storage mode (requires SDK support)
3. Supports BLE custom command send mode
4. Supports showing the frequency offset and other device information in rotation
5. Fixed a compatibility issue with UFW files containing many files
6. Optimized the time from a timeout disconnection to being ready for a new connection
7. Fixed an issue where TWS pairing could occasionally fail after the out-of-case in-ear trim or post-pairing power-off enable settings were changed

V126

2021-12-20

Supports JL6976M and AC701N upgrade
Fixed an issue in V1.2.5 where the configuration had to be saved once before Bluetooth search worked
Added the out-of-case in-ear trim function (requires SDK support)
Added the option to power off when taken out of the case after pairing (requires SDK support)
Added connecting to devices to be upgraded by Bluetooth name prefix
Added the storage mode command test function
Added battery level, address and checksum verification
Added the 2.4G connection function

V125

2021-09-29

Fixed some Chinese display issues on the test box
Supports Bluetooth calibration signal transmit mode and frequency point configuration (for frequency calibration during programming with the 1-to-8 tool)
Improved BLE connection compatibility
Supports SBC-encoded 44.1khz line-in audio sources
The PC configuration interface supports the new UFW of the 695N series (older versions report that the target file cannot be found)

V124

2021-03-20

Added the classic Bluetooth TWS connection support setting (requires SDK support)
Added support for multiple test items over UART communication (requires ota.bin support)
Added support for baud rates below 100k (requires ota.bin support)
Supports wired UART custom command configuration (requires SDK support)
Optimized the PC configuration interface

V123

2020-12-18

Supports parsing UFW files generated by the new SDK (fixes "Error: unsupported firmware file format" (错误：不支持的固件文件格式))
Supports battery level and checksum display (requires SDK support)
Supports the battery level check before upgrade (requires SDK support)
Supports AD699N/AD698N UART upgrade
Fixed an erase timeout when upgrading large-capacity flash

V122

2020-10-15

Supports the TWS enter-DUT command setting
Supports 698x Bluetooth testing and upgrade
Supports the setting for switching test items with the PP button of the target device
Supports pairing code verification during TWS pairing
Supports displaying long device names in rotating segments
The PC interface supports remote upgrade of the test box firmware
Fixed recognition errors with some UFW files in the PC interface

V121

2020-07-08

Supports BLE master frequency offset test and calibration
Improved TWS pairing error handling
Added the TWS test setting to disconnect Bluetooth when an earbud is taken out of the case
Fixed a Bluetooth connection timeout with devices that do not support advanced audio
Fixed BLE frequency offset test issues (affecting 693x, 695x, 696x, 697x)
Supports matching TF card upgrade files by extension only (.ufw/.bfu files)
Fixed an issue where the TWS test might not connect when only one earbud was inserted
Supports AD697N and AC897N upgrade
Added some configuration items to the PC tool (see the section "V121 new configuration items")

V120

2020-04-08

Supports 697x wireless and UART upgrade
Supports upgrade of some 695x flash chips
Improved the TWS test UI
Fixed Bluetooth names longer than 30 bytes not being displayed
Supports test boxes with an active crystal oscillator

V119

2020-01-08

Supports AI8009 wireless upgrade
Improved the upgrade progress display (preparation progress and upgrade progress are shown separately)
Fixed the frequency offset not being displayed over a classic Bluetooth connection with the data transfer SDK
Supports 692x_v2_sdk wireless upgrade
Supports 696x wireless and UART upgrade

V118

2019-10-21

Supports ai800x_sdk_v2.0.0 wireless and UART upgrade
Supports 695x wireless and UART upgrade
Supports 693x BLE testing and wireless upgrade
Changed BLE device name matching to prefix matching

V117

2019-06-03

Test box hardware version v2.2 supports 693x UART upgrade

V116

Support for test box hardware version v2.2 (added the TWS communication interface)
Adjusted the PC tool interface and optimized the search and connection process
Fixed support issues with the AC46x and AC690x_v100 series SDKs
(Note: firmware v116 and v216 are the same firmware; it is shown as v2.1.6 on v2.2 hardware and as v1.1.6 on hardware earlier than v2.2)

Supports matching the upgrade file against the chip model before upgrading (except AC691x and AC692X, which cannot be distinguished)
Improved support for AC693X upgrade and testing

V111

Improved test box Bluetooth search and UART communication stability

Added opening and reading of the upgrade file updata.bfu (i.e., support for ac692x Bluetooth wireless upgrade).
