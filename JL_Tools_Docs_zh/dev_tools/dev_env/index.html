1. 开发环境安装说明

1.1. Windows 环境

SDK工程默认支持在 Windows 系统上，用 Code::Blocks 开发。

配置环境主要分为三步：

  1. 下载并安装 Windows版Code::Blocks（点击此处下载）

  2. 打开安装好的 Code::Blocks 后，关闭 Code::Blocks （这是为了让Code::Blocks生成一些基础设置信息）

  3. 下载并安装 最新版本的杰理Windows版工具链（点击此处下载）

到现在，你已经可以打开 Code::Blocks 工程进行编译开发了，具体方式，参考 SDK 编译以及下载。

Note

第一次使用 Code::Blocks 编译可能会有 Security Warning 弹窗。 解决方法见：编译的时候提示Security Warning与链接的时候，提示无法找到@xxx.objs.txt文件。

1.2. Linux 环境

目前默认情况下，SDK 工程支持在 Linux 环境下使用 Makefile 进行开发编译，参考使用 make 进行编译。

  • SDK 的后处理脚本download.sh经过修改（参照对应 Windows 版本的download.bat）后，可以生成.fw固件文件。

  • 不支持下载固件到设备中。

工具链以及下载目录后处理工具下载链接，参考：工具最新版本
