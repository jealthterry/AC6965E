2.21. Troubleshooting Common Errors

The following table lists common errors that can occur when using the 1-to-8 programmer and how to handle them.

No.

Common error

Solution

1

Repeated errors when updating the target chip firmware
or remotely upgrading the programmer firmware

Follow the correct steps in the corresponding section;
if it still fails, record the error message and consult Jieli technical support promptly

2

Errors on the display at power-on or during chip programming

See the section "LCD display error messages" and handle the error as described there

3

Defect rate too high in mass-production programming

Record the type of programming failure error and describe the operating procedure in detail;
send the failed chips to Jieli through the appropriate process for further analysis by engineers.

4

The chip does not start after successful programming

Blank check mode may have been used during programming, or the chip firmware was not programmed successfully for some other reason;
use verification mode to check whether the chip firmware is complete
The cause may be the chip itself or an SDK problem; describe the production process in detail
and send the defective chips to Jieli through the appropriate process for further analysis by engineers

5

The channel progress bar is green

The current channel was not programmed successfully;
this is usually caused by the programmer firmware hanging, so try programming again
If programming still fails after several retries, the chip may be faulty; replace the chip and try again
If programming fails with several different chips, consider a programmer bug;
collect failure-rate statistics and contact Jieli technical support promptly

6

Programming failures after updating the programmer
to the latest firmware

The latest programmer firmware may have added certain test items
to screen out chips that do not meet performance requirements. If many failures appear after updating the programmer to the latest firmware,
record the programming error messages and report them to Jieli technical support promptly

7

When deploying a programming file,
the error "Chip KEY does not exist" (不存在芯片KEY) appears

If the error occurs with a special version, ask whether that version is intended for a specific chip;
if the error occurs with the public version, contact weiyushu@zh-jieli.com for support and update the public version again
