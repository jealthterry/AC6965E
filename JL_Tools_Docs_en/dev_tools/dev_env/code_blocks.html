1.1.1. Installing Code::Blocks

Code::Blocks can be downloaded either from the official website or directly from the mirror on the Jieli website.

1.1.1.1. Download and install from the Jieli tools website

  • Open the following link in a browser: Code::Blocks for Windows (click here to download)

  • Double-click the downloaded codeblocks-latest.exe and follow the prompts to install it.

1.1.1.2. Download and install from the official CodeBlocks website

  • First, open the official Code::Blocks website.

  • On the download page shown below, download the latest version, codeblocks-20.03-setup.exe. After the download, double-click the file and follow the prompts to install it.
