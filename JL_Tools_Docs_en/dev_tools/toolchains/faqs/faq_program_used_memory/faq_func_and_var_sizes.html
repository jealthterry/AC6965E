4.1.7.2.1. Generating symbol_tbl.txt

Note

The symbol_tbl.txt currently generated in the SDK is not produced with llvm-objsizedump.exe and does not meet the requirements, so use the following script

Get the report_size_usage.bat script

Put the following script in the directory where sdk.elf is located and double-click it to run it:

Download the symbol size summary tool (click here to download)

Note: the text of the script is as follows:
@rem Place this script in the download directory
@rem It writes the space used in sdk.elf,
@rem sorted by address, to symbol_tbl.txt
set OBJSIZEDUMP=C:\JL\pi32\bin\llvm-objsizedump.exe
set ELF=sdk.elf
set OUTPUT=symbol_tbl.txt

Double-click the script to run it
