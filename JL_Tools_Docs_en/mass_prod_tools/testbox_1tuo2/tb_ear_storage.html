3.8. Using Earphone Storage Mode

3.8.1. Feature overview

To reduce battery drain of earphone products during long-term storage or shipping, the test box can trigger the earphones to enter storage mode when they are about to be packed. The storage mode command makes the earphones turn off touch wake-up and other functions to reduce standby power consumption; earphones in storage mode can only be woken up and powered on via LDOIN.

3.8.2. Operation

  1. Test box PC tool settings

[1] Connect the test box to the PC and press and hold the rightmost button on the test box to enter PC configuration mode; the test box shows "LOADING";

[2] On the "Wired UART mode configuration" (有线串口模式配置) page of the PC tool, set "Storage mode command enable" (仓储模式命令使能) to "1" to turn on storage mode.

To check whether pairing information has been written to the current TWS earphones before they enter storage mode, set "Storage mode with pairing check" (仓储模式带配对判断) to "1" to turn on this feature.

When "Show pairing address on storage mode pairing check failure" (仓储模式配对判断失败显示配对地址) is set to "0", the common address and "Not paired" (未配对) are displayed.

When "Show pairing address on storage mode pairing check failure" (仓储模式配对判断失败显示配对地址) is set to "1", the local address L and the address of the other, already paired earbud (the remote address) R are displayed.

[3] Click "Save settings to test box" (保存设置到测试盒);

  1. Test box DIP switch settings

This mode does not depend on the positions of the test box DIP switches.

  1. Procedure Scenario 1: without pairing check

[1] After configuration, reset the test box; it enters the storage mode command screen.

[2] Place the device under test in the fixture connected to the test box (see "Connecting the Test Box to a Fixture over UART"). When a response is received from the device, "Command response" (命令应答) is displayed, accompanied by a beep.

Scenario 2: with TWS pairing check enabled

[1] After configuration, reset the test box; it enters the pairing check screen

[2] Place the TWS earphones under test in the fixture connected to the test box to check their pairing information.

  • If the pairing does not match, an error is reported with a long beep (removed in v126d) and the same prompt tone as for a pairing error (added in v132). When the "Show pairing address on storage mode pairing check failure" (仓储模式配对判断失败显示配对地址) option is set to 0, the LCD shows the COMMON address of each earbud (if both common addresses are 0, neither earbud has ever been paired, which is also reported as an error), together with a "Not paired" (未配对) message.

  • When the "Show pairing address on storage mode pairing check failure" (仓储模式配对判断失败显示配对地址) option is set to 1, the LCD shows the local address of each earbud (starting with L) and the remote address received from the paired earbud (starting with R) (if there is no remote address, neither earbud has been paired, which is also reported as an error).

  • If the pairing matches, the storage mode command is sent automatically. When the device responds successfully, "Command response" (命令应答) and "Paired" (已配对) are displayed, with a short beep.
