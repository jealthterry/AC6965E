当点击【运行】或者【编译后调试】的按钮（即， 这两个按钮），会出现类似如下的提示：

这是因为，小机的程序不是 Windows 应用程序，无法在 Windows 上运行（而是在样机上运行）。

Note

如果点击的是【编译】按钮，但仍然弹出了这个错误，那一般是因为你的电脑被感染了病毒，杀毒后再尝试。（这是因为有些病毒会尝试感染并运行所有被编译出来的文件）。
