1.2.2. Permissions

1.2.2.1. License file

To modify firmware with this tool, you need a license file for authorization verification.
A license file is a file with the lic extension: *.lic

After you select an FW or UFW file, the tool prompts you to select a matching license file, as shown below:

If you are a Jieli first-tier distributor, contact the Jieli Shenzhen office to obtain the license file.
If not, contact your distributor to obtain the license file.

If no license file is selected, the tool does not allow the firmware file to be modified.
All edit boxes are set to read-only, as shown below:

After the correct license file is selected, all edit boxes become editable, as shown below:

1.2.2.2. The edit_cfg.ini file

The edit_cfg.ini file is designed to let project managers specify which files in the firmware file can be modified and which cannot.

The contents of the edit_cfg.ini file are as follows; you can copy them directly into the SDK.

[EDIT_PERMISSION]
;Whether modification is allowed, true by default
ENABLE = 

[FLASH_BIN]
;Blacklist: files that may not be modified
BLACK_LIST = 

;Other files that may be replaced
REPLACE_LIST = 

[FW]
;Reserved-area resources in the FW file that may be replaced
RESERVED_LIST = 
				
[UFW]
;Reserved-area resources in the UFW file that may be replaced
RESERVED_LIST =

As shown below:

Place the edit_cfg.ini file according to the actual SDK directory structure (you can use the location of isd_config.ini as a reference).

1.2.2.3. How to add the edit_cfg.ini file to the firmware file

After you add the edit_cfg.ini file to FW_ADDITIONAL/FILE_LIST in isd_config.ini, isd_download.exe packages it into the firmware file when it generates the firmware file, as shown below:

Note

  • If there is no FW_ADDITIONAL/FILE_LIS section in isd_config.ini, you can simply add it.

  • If isd_config.ini is generated from isd_config_rule.c, modify the isd_config_rule.c file instead.

1.2.2.4. Other notes

The tool currently supports original FW/UFW files and FW/UFW files authorized in unlimited authorization mode.

After the tool loads the license file, the following modifications and replacements are allowed by default

  1. Change the Bluetooth name

  2. Replace prompt tone file data

  3. Replace EQ file data
