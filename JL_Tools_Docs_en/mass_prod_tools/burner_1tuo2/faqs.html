1.12. Troubleshooting Common Errors

The following table lists common errors that occur when using the 1-to-2 programmer and how to handle them.

No.

Common error

Solution

1

Errors when repeatedly updating the target chip firmware
or remotely upgrading the programmer firmware

Follow the correct steps described in the corresponding sections;
if this does not help, record the error message and promptly consult Jieli technical support

2

Errors on the display at power-on or during chip
programming

See the "Status Indicators and Error Messages" section and handle the error as described there

3

Defect rate too high in mass-production programming

Record the error types of the failed chips and describe the operating procedure in detail;
follow the appropriate process to send the failed chips to Jieli for further analysis by engineers.

4

The chip does not start after successful programming

Blank check mode may have been used for programming,
or the chip firmware was not programmed successfully for some other reason;
you can use verification mode to check whether the chip firmware is complete.
If the cause is the chip itself or an SDK problem, describe the production process in detail
and follow the appropriate process to send the defective chips to Jieli for further analysis by engineers;

5

Programming failures after updating the programmer
to the latest firmware

The latest programmer firmware may have added some test items to screen out
chips whose performance does not meet the specification; if many failures occur after updating the programmer to the latest firmware,
record the programming error messages and promptly report them to Jieli technical support
