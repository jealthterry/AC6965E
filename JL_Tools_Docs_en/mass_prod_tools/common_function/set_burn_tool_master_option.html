6.2. How to Set Expert Options When Generating a Programming File

6.2.1. How to modify the INI expert configuration options

To set specific programming options, you can set the values of those options in the INI configuration file.

Note

ISD_DOWNLOAD.EXE in the download directory must be updated to version 4.2.53 or later.

Open the isd_config.ini file in the SDK download directory and add the configuration section [MASTER_CONFIG_OPTIONS].

Important

Note: In some SDKs, the isd_config.ini file is generated by preprocessing isd_config.c.

If you edit isd_config.ini directly and then rebuild, you may find that isd_config.ini has been changed back. Check whether this is the case for the SDK you are using. If it is, you need to modify isd_config.c instead.

For convenience, the following text continues to use the isd_config.ini file as the example.

Configure the default values of the specified programming options according to your actual needs. The LVD_LEVEL setting and the LVD_RST_EN enable are used as an example below:

[MASTER_CONFIG_OPTIONS]
LVD_RST_EN=TRUE
LVD_LEVEL=2.5v

In addition, the expert mode options of each chip have different associated options, which must be configured together; otherwise an error occurs.
For example, for the AD17N chip the associated options are LVD_RST_EN, LVD_LEVEL, MAIN_IOVDD_LEVEL, WEAK_IOVDD_LEVEL. If you configure some of the associated options, you must also configure the rest.

[MASTER_CONFIG_OPTIONS]
LVD_RST_EN=TRUE
LVD_LEVEL=2.5v
MAIN_IOVDD_LEVEL=3.4v
WEAK_IOVDD_LEVEL=3.4v

Incorrect values also cause errors. Set enable-type options to TRUE or FALSE, and set voltage-type options to the required voltage value. Make sure the configured voltage matches one of the voltage levels supported by the chip; do not configure a wrong value.

Note

For older SDKs, the following additional steps are required: (for newer SDKs, you only need to modify isd_config.ini)

  1. For the AC690X, AC691X, AC692X SDK V1, AC61N, AC62N, AC64N and AC81N SDKs, use fw_add.exe (version 1.0.15 or later) to add the isd_config.ini file to the FW file. Example command:

fw_add.exe -fw <original.fw> -out <modified_output.fw> -add isd_config.ini -type 0x34

  1. For the AC13N SDK, use the -ini parameter of bin_to_fw_v2.exe (version 2.0.8 or later) to add the isd_config.ini file to the FW file. Example command:

bin_to_fw_v2.exe -flash <bin_file.bin> -key <key_file.key> -log info.log -chip AD13N -out <output_file.fw> -ini isd_config.ini

  1. AC1X series and AC3X series chips are not supported at present.

6.2.2. Which expert options can be configured in the INI file

Expert mode is intended for configuration by expert-level engineers; for details, see the EFUSE documentation provided by the IC team. For the expert options supported by each chip model and their allowed values, see the configuration description of the corresponding chip below.

Important

  1. TRUE: the option is checked in the UI; the corresponding efuse bit is programmed to 1

  2. FALSE: the option is unchecked in the UI; the corresponding efuse bit is programmed to 0

  3. Specific voltage values corresponding to the LVD and IOVDD level settings

  4. PINR: corresponds to long-press reset; MCLR corresponds to short-press reset

  5. In general, EN_ACT=FALSE; must be configured for the other bit settings to take effect

Note


Note:
1. The option IDs and option values in the INI file are case-sensitive.
2. Update isd_download.exe to version 4.2.56 or later, preferably to the latest version.
3. The storage medium is one-time programmable: once an option has been programmed to FALSE, it cannot be programmed back to TRUE. Jieli engineers must carefully check the efuse reference documentation before configuring.


4. In general, EN_ACT, LVD_RST_EN and IOVDD_LEVEL are associated options: if you configure other options in the [MASTER_CONFIG_OPTIONS] section, the configuration must also include the associated options. If the [MASTER_CONFIG_OPTIONS] section is not configured, you can select the corresponding LVD voltage level for programming on the "Configuration" (配置) screen of the FW file deployment interface.
5. Some models do not require the associated options to be configured; for example, on the JL708N chip, LVD_LEVEL and IOVDD_LEVEL have their own LVD_ACT and IOV_ACT activation enable bits.

6. To disable the LVD reset function, configure as follows (EN_ACT and LVD_RST_EN must be set to FALSE):
[MASTER_CONFIG_OPTIONS]
EN_ACT=FALSE
LVD_RST_EN=FALSE
LVD_LEVEL=2.5v
IOVDD_LEVEL=3.0v
