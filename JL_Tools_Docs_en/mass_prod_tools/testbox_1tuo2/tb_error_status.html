3.13. Status Indicators and Error Messages

3.13.1. Status indicators

During power-on, testing and upgrading, the LCD display of the test box shows the status of each operation. For details, refer to the corresponding LCD display images in the function module descriptions of each section.

3.13.2. Error messages

While testing or upgrading, the test box may fail to test or upgrade for some reason; the LCD display then shows error messages for the errors that occur during testing, upgrading and other processes.
