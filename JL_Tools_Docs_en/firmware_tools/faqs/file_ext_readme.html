1.4.2. File Types Explained

While in use, the PC tools read or output various types of files.

File type

Description

Purpose

How to obtain

*.fw

Firmware file

For programming blank or non-blank chips

Generated by isd_download in the download directory

*.ufw

Firmware file

For programming non-blank chips, or for OTA upgrades

Generated by isd_download in the download directory, or generated by editing with the configuration tool

*.key

KEY file distributed by Jieli

Used by isd_download to generate FW or UFW files with a KEY

Contact Jieli to obtain it

*.lic

LIC file distributed by Jieli

A lic file corresponds to a KEY file and can only be used by the editing tool to edit UFW files
Do not confuse it with the toolchain License file; they are different things that just happen to have the same extension

Contact Jieli to obtain it (in the same way as *.key files)

Important

Old versions of the toolchain (the latest version no longer requires this) also need a License file to be imported, and this License file also happens to have the .lic extension. The License file used by the toolchain and the LIC file used by the editing tool here are not the same thing. Do not confuse them.
