1.3.2. Connection Modes

1.3.2.1. USB mode

This mode can be used only when the product itself is not connected to a power supply.
In this mode, you do not need to select the chip type or whether there is a power supply; the device type is detected automatically once the product is connected with the Forced Upgrade Tool, as shown below:

1.3.2.2. Serial port mode

In this mode, you must manually select the chip type used by the product.
This mode requires the serial port upgrade function of the Forced Upgrade Tool.
The "With power supply" (有电源) option is an optional setting for products that have their own power supply; selecting it speeds up communication. (This requires support in the SDK; if the SDK does not support it, opening fails.)

1.3.3. Open Options

  1. The "Auto update" (自动更新) option writes the Bluetooth address, Bluetooth name or authentication code to the product immediately after it is modified.

  2. The "Auto read after update" (更新后自动读取) option automatically reads back the corresponding information after the Bluetooth address, Bluetooth name or authentication code is updated, so that you can check whether it was changed correctly.

  3. The "Auto read" (自动读取) option automatically reads the corresponding information after the product is opened.

  4. The "Manual input" (手动输入) option determines whether the input cursor is reset periodically. When it is checked, the input cursor is not reset periodically. Leave it unchecked when using a barcode scanner.

  5. The "Auto reset" (自动复位) option determines whether the product is reset automatically after the Bluetooth address, Bluetooth name or authentication code is updated.

  6. With the "Mark duplicates" (重复标记) option, the Bluetooth address or authentication code that is read is saved to read.xlsx in the tool's directory, and duplicates are highlighted in red. Note that when this option is checked, "Query" (查询), "Auto query" (自动查询) and "Auto read after update" (更新后自动读取) all save the information to read.xlsx. So if "Auto read after update" is checked, do not also click the "Query" button or check "Auto query", to avoid duplicate entries.

  7. The "Query Bluetooth address and authentication code" (查询蓝牙地址和认证码) option allows the Bluetooth address and the authentication code to be queried together during a query or auto query.
