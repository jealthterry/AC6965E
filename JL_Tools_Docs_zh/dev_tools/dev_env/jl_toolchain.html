1.1.2. 安装杰理工具链

Note

杰理工具链 不再需要申请并导入license文件 ，用户安装完之后就可以直接使用。

目前SDK编译只支持 Windows 与 Linux 操作系统。各自安装方式如下：

1.1.2.1. Windows 操作系统

  • 在确保当前机器已经安装好 CodeBlocks 之后，就可以开始安装杰理工具链，点击链接 Windows工具链（点击此处下载） 下载工具链

  • 双击下载的文件后，按提示进行安装即可。

1.1.2.2. Linux 操作系统

  • Linux 操作系统下，只支持通过 make 方式编译SDK。工具链下载地址：Linux工具链（点击此处下载）。解压到 /opt/jieli 目录下，保证 /opt/jieli/common/bin/clang 存在（注意目录层次）

  • 由于 Linux 下有打开文件数量的限制，而链接过程会打开较多文件，可能会导致链接失败。确认 ulimit -n 的结果足够大（建议大于8096），可以通过 ulimit -n 8096 来设置一个较大的值。
