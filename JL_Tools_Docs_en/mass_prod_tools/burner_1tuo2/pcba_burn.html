1.10. Chip Programming Wiring and Power Supply

1.10.1. Minimum chip system for programming

Solder a 105 filter capacitor from each power supply pin of the chip (bare chip) to GND, connect a 24M crystal to the crystal pins (no crystal is needed for crystal-less designs), and wire the chip's VBAT, DM, DP and GND pins (on some chips, other pins are used instead of DM and DP) to the corresponding pins of the channel 1 or channel 2 pin header on the programmer. The chip can then be programmed, as shown in Minimum chip system for programming.

Note

  • For mass-production programming, all power pins, such as VPWR, VBAT, IOVDD, DCVDD, HPVDD and VCM, must be connected to filter capacitors, and a calibration circuit may also be needed. For details, see the programming hardware schematic for the corresponding model provided by Jieli.

1.10.2. Programming channel pin header definitions and wiring

  1. The pin header definitions and the wiring reference diagram for programming channel 1 or channel 2 are shown in Wiring reference for a programming socket or device.

  1. Wiring with an LDO voltage conversion circuit

    As shown in Wiring reference for a programming socket or device, the programming socket has an LDO voltage conversion circuit: the LDO hardware circuit converts the "6.5V" pin of the programmer pin header to the programming voltage required by the chip, such as 5V or 4.2V, and the programmer controls the power supply to the chip by switching the LDO supply on and off through the 3.3V header pin. The connections between the programmer header pins and the chip programming pins are as follows:

DP (some chips have no DP and use another pin)

GND

  1. Wiring with the chip supply voltage output directly from the programmer's power pin

    As shown in Wiring reference for a programming socket or device, ignore the LDO part when wiring. The "6.5V" pin of the programmer pin header directly outputs the programming voltage required by the chip as configured in the PC tool, such as 5V or 4.2V. Note

  • Programming sockets used to have an LDO conversion circuit because it was expected that some uncalibrated chips might reach customers and would then have to be calibrated by the programmer, or because programming the efuse storage medium of some chips requires specific voltages such as 6.5V or 3.3V;

  • The current programmer has a chip calibration check function: if a chip is not calibrated, programming reports an error! In addition, programming the efuse-related key, lvd, etc. no longer requires specific voltages;

  • The LDO circuit can be removed from the programming socket, and the socket can be built as a minimum chip system for programming! This makes the programming socket simpler, saves materials and allows it to be used as a universal programming socket;

  • Powering the chip through an LDO conversion circuit also has advantages: shorter traces, a relatively more stable power supply and possibly a higher programming pass rate;

1.10.3. Power supply for chip programming

With firmware version V2.27.9 or later, the 1-to-2 programmer allows the programming socket supply voltage to be configured in the PC tool within "4.2V~6.8V". There are three main use cases:

  • Without an LDO circuit: the "6.5V" pin of the programmer pin header directly outputs the voltage configured in the PC tool, such as 5V or 4.2V, to the chip's VBAT supply pin.

  • With an LDO voltage conversion circuit: a hardware circuit converts the 6.5V from the programmer pin header to the supply voltage required by the chip, such as 5V or 4.2V; the supply voltage must be set to "Default".

  • Low-voltage programming supply, for example when IOVDD and VBAT are tied together: VBAT can be connected directly to the 3.3V pin of the programmer pin header, or the 6.5V from the programmer pin header can be converted to the supply voltage required by the chip.

The programming voltage configuration window is shown below:

Note

  • If the supply is configured as "4.2V" by default and the socket has an LDO circuit, remember to set the supply voltage back to "default" when programming; otherwise, insufficient power may cause various programming problems!

  • Do not program device chips without an LDO circuit with the supply voltage set directly to "default"; otherwise, the excessive supply voltage may burn out the chip!

1.10.6. Wiring for calibrating device chips

With this wiring method, chips on devices, DEMO boards and development boards can be programmed and tested, and the chips can also be calibrated.

A simple method is to take a top board for an SOP package (easy to solder wires to) and bring out VBAT (or LDOIN/VPWR), DM, DP, GND and the PB1 2.5V reference source from the socket,

and connect them to the corresponding pins of the device chip, as shown in Wiring for calibrating a device chip. Then follow the normal programming procedure to calibrate the chip and program the firmware.

Note

  1. On the top boards of some chips, the 2.5V reference source is not necessarily connected to PB1; it depends on the specific hardware design;

  2. On some chips, the calibration power supply is connected to VBAT rather than to the LDOIN/VPWR pin;

  3. Mass-production chips are calibrated at the factory; they are calibrated again during programming only if modules such as the ADC module or the VBAT charging module are not accurate enough;
