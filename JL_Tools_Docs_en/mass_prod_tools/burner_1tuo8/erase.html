2.19. Partial (Non-Full-Chip) Erase

2.19.1. How to enable it

For cases where a chip needs to be reprogrammed while keeping some of its original data, the programmer provides a partial (non-full-chip) erase function for some chip models.

For chip models that support partial erase, the programming configuration screen shows an "Erase VM" (擦除VM) checkbox. Uncheck the option "Erase the entire flash before programming" (烧录前擦除整个flash) to enable partial erase.

2.19.2. Description

  1. If "Erase the entire flash before programming" (烧录前擦除整个flash) is checked, the programmer erases the chip's entire flash and no information is kept.

  2. If "Erase the entire flash before programming" (烧录前擦除整个flash) is not checked:

    • If "Erase VM" (擦除VM) is checked, the programmer erases the program area and the VM area of the flash and keeps the information in the other areas.

    • If "Erase VM" (擦除VM) is not checked, the programmer erases only the program area of the flash and keeps the information in all other areas.

  3. To keep the original Bluetooth address, do not check "Update Bluetooth address" (更新蓝牙地址).

  4. To keep the original authentication code, do not add an authentication code file.
