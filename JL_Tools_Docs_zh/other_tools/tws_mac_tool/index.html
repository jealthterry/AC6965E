1. TWS配对地址分析工具

1.1. 工具介绍

TWS配对地址分析工具用于读取解析TWS耳机配对地址信息。

  • 本工具需要联网使用，并且需要经过杰理科技授权才能使用。*

在您还未经过杰理科技授权时打开工具会提示以下信息。
请按照工具提示，将相关信息发送给杰理科技lvjianbing@zh-jieli.com申请工具的使用权限。

再通过授权后，再次运行工具，将不再提示需要授权，界面如下图：

此时，将样机通过杰理强制升级工具4.0将样机与电脑连接后，选择当前样机与电脑的连接方式和样机芯片型号后，
点击分析按钮，工具将显示样机中所有TWS配对地址信息。如下图：

1.2. 分析方法

（1）如果耳机正常配对，L耳机上的本地地址是R耳机上的远端地址；R耳机的本地地址是L耳机的远端地址。L和R耳机配对其生成的公共地址，在L耳机和R耳机上其公共地址是相同的。
（2）如果软件选择使用左耳地址作为公共地址，那么公共地址与L耳机的本地地址一样。
（3）耳机的配对信息上可能出现多个远端地址和公共地址，说明这个耳机还有与其他耳机配对过，里面存在其他耳机的本地地址。
（4）配对记录从上往下是从旧到新，最新一条配对记录就是样机当前的配对状态。
