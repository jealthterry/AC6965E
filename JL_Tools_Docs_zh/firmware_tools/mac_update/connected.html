1.3.2. 连接模式说明

1.3.2.1. USB模式

产品需本身未连接电源下才能使用该模式。
该模式下无需选择芯片类型和是否有电源，使用强制升级工具连接产品后自动识别设备类型。如下图：

1.3.2.2. 串口模式

该模式下需手动选择产品使用的芯片类型。
该模式下需使用强制升级工具的串口升级功能。
有电源选项是在产品本身带有电源的情况下提供的一个可选选项，选择此选项后可以加快通信速度。（需要SDK本身支持，若不支持则会打开失败）

1.3.3. 打开选项说明

  1. 自动更新选项是指在修改蓝牙地址、蓝牙名或认证码后立刻更新到产品中。

  2. 更新后自动读取选项是指在更新蓝牙地址、蓝牙名或认证码后会自动读取对应信息，便于查看是否修改正确。

  3. 自动读取选项是指在打开产品后自动读取对应信息。

  4. 手动输入选项是指是否会定时复位输入光标，勾选后则不会定时复位输入光标，使用扫码枪情况下不勾选。

  5. 自动复位选项是指更新蓝牙地址、蓝牙名或认证码后是否会自动复位产品。

  6. 重复标记选项是指在读取蓝牙地址或认证码时会将读取到的信息存入工具同一目录下的read.xlsx内，有重复的会标红。注意勾选后查询、自动查询和更新后自动读取都会将信息存入read.xlsx内，所以勾选更新后自动读取后，不要再点击查询按钮或勾选自动查询，避免信息重复。

  7. 查询蓝牙地址和认证码选项是指在查询或自动查询时，可以同时查询蓝牙地址和认证码。
