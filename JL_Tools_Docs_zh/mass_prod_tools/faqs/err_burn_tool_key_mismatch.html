7.1. 固件文件KEY与烧录器KEY不匹配

在部署文件到一拖二烧录器或者一拖八烧录器的时候，工具提示类似下面的错误：

固件文件中包含了KEY，同时烧录器也包含了KEY（烧录器的KEY在出厂的时候，已经固化，与代理商绑定，用户不能修改）。当两者不匹配的时候，会出现报错。

出现这个错误的原因主要有下面几种：

  1. 固件文件生成的时候，未指定 -key 参数，导致生成的固件文件并没有 KEY。 解决方法：在下载目录中，修改生成固件文件的脚本，指定参数-key keyfile.key。其中keyfile.key是从杰理公司获取的KEY文件。如下图所示：

Note

  1. 如果你的 KEY 文件名字中有空格。建议去掉空格。或者用双引号 “” 括起来，例如 “key file with space.key”。

  2. 为了避免输错文件名导致的问题，建议 key 文件中不要包含任何空格、中文字符等，只包含英文和数字。

  1. 固件文件生成的时候，指定了错误的KEY文件。具体请咨询代理商或者杰理公司。

  2. 可能当前烧录器未能支持烧录对应的芯片。具体请咨询代理商或者杰理公司。
