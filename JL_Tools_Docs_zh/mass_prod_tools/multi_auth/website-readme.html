4.4. 杰理服务器使用方式

4.4.1. 账户注册

在浏览器中，打开网址：https://fmfile.jieliapp.com/user/register 进行账户注册

Important

  • 如何获取邀请码？

  • 如果您是算法提供商，请发送邮件到 杰理原厂：jlkf@zh-jieli.com邮箱申请。
    邮件主题：多算法授权申请-xx公司
    公司名称请填写公司全称
    正文内容：
    1.角色：算法提供商
    2.公司介绍：如本公司是算法公司，专注于xxxx的研发，客户有xxxx、xxxx、xxxx，
    3.代理商编号及名称：如128杰理科技
    4.芯片名称：如JL7006D
    5.方案类型：如音箱、耳机等
    6.使用场景描述：如跟xx公司合作，我公司负责xxx，某某公司负责xxx，需要多算法授权解决xxx问题

  • 如果您是生产商，请通过您的算法提供商发送邮件到 杰理原厂：weiyushu@zh-jieli.com邮箱申请。
    邮件主题：多算法授权申请-xx公司帮助xx公司申请邀请码
    公司名称请填写公司全称
    正文内容：
    1.角色：生产商
    2.方案公司介绍：如使用我公司算法的生产商公司是xx公司，专注于xxxx的研发，客户有xxxx、xxxx、xxxx，
    3.芯片名称：如JL7006D
    4.方案类型：如音箱、耳机等
    5.使用场景描述：如xx公司跟我公司合作，需要多算法授权解决xxx问题
    6.生产商邮箱地址：xx公司对接人员的邮箱地址

4.4.2. 用户登录

在浏览器中，打开网址：https://fmfile.jieliapp.com/user/login 进行账户登录

4.4.3. 用户首页

用户登录后，会自动重定向到：https://fmfile.jieliapp.com/

4.4.4. 更新用户密码

在用户首页，可以找到按钮【更新密码】，点击后进行密码更新操作。
