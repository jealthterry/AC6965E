1.3.1. Overview

The purpose of this tool is to help project managers quickly modify the Bluetooth address, Bluetooth name and authentication code in products that have already been programmed.

This tool supports the following modes for connecting to products:

  1. USB

  2. Serial port

This tool supports the following functions:

  1. Update the Bluetooth address

  2. Update the Bluetooth name

  3. Update authentication codes
