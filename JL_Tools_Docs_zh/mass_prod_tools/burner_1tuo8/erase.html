2.19. 非全片擦除功能

2.19.1. 开启方法

对于有重新烧录需求又想保留芯片原本的一些数据的情况，烧录器对部分芯片型号添加了非全片擦除功能。

添加了非全片擦除功能的芯片型号的烧录配置界面可以看到擦除VM的勾选项。不勾选烧录前擦除整个flash的选项，即可开启非全片擦除功能。

2.19.2. 说明

  1. 勾选了烧录前擦除整个flash则烧录器会对芯片flash全部擦除，不会保留信息。

  2. 没有勾选烧录前擦除整个flash的情况下

    • 勾选了擦除VM，烧录器则会擦除flash的程序区和VM区，保留其它区域的信息。

    • 没有勾选擦除VM,烧录器则只擦除flash的程序区，保留所有其它区域的信息。

  3. 如果需要保留原本的蓝牙地址，请不要勾选更新蓝牙地址。

  4. 如果需要保留原本的认证码，请不要添加认证码文件。
