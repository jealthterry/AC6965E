4.1.8. Why Does Linking Warn "stack size limit exceeded"?

In the final link stage, some SDKs may report warnings similar to the following:

/opt/pi32v2/bin/pi32v2-ld: warning: LLVM gold plugin: stack size limit exceeded (288) in __os_taskq_del
/opt/pi32v2/bin/pi32v2-ld: warning: LLVM gold plugin: stack size limit exceeded (276) in hci_send_event
/opt/pi32v2/bin/pi32v2-ld: warning: LLVM gold plugin: stack size limit exceeded (280) in vm_data_copy

This warning means that the stack space used by these functions exceeds a certain threshold. The number in parentheses is the stack space used by the function, and the last item is the function's name.

For example, the following line:

/opt/pi32v2/bin/pi32v2-ld: warning: LLVM gold plugin: stack size limit exceeded (288) in __os_taskq_del

means that the function __os_taskq_del uses 288 bytes of stack space, which exceeds the threshold we set.

This warning only tells programmers which functions use a large stack; it does not mean that an error will occur at run time.

To set the check threshold:

# Compiler flags: (using a threshold of 256 as an example)
-Wframe-larger-than=256

# Linker flags: (using a threshold of 256 as an example)
--plugin-opt=-warn-stack-size=256

For how to set this in a Code::Blocks project, see:

  • How to Add Compiler Flags

  • How to Set Linker Flags
