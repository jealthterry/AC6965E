4.3. The isd_config.ini Configuration File

4.3.1. Configuration sections

Section name

Description

[EXTRA_CFG_PARAM]

Configures the information required before flash.bin is generated.

[SYS_CFG_PARAM]

Configures the parameters required by the system. All options in this section are converted and then stored in flash.bin.

[TOOL_CONFIG]

Configures information related to the tools.

[CHIP_VERSION]

Configures information related to the chip version.

[RESERVED_CONFIG]

Section for configuring reserved-area information. If the RESERVED_OPT option is set in the [EXTRA_CFG_PARAM] section, at most 6 entries can be configured in this section.

[RESERVED_EXPAND_CONFIG]

Section for configuring reserved-area information, like [RESERVED_CONFIG]. This section was added in case the [RESERVED_CONFIG] section is not sufficient.

4.3.2. Options

The default value is the value used when the option is not present.

The valid values are the values that the option accepts.

4.3.2.2. [SYS_CFG_PARAM] section options

  • The settings in this section are custom settings. They are converted and stored in flash.bin for use by the firmware.

  • Currently available settings:

Setting

Description

SPI=2_3_0_0

Configures the SPI parameters. The value to the right of the equals sign means datawidth_clk_mode_port

OSC=btosc

Parameter used to specify the system clock source; usually commented out

OSC_FREQ=12MHz

Parameter used to specify the FREQ frequency; can be 12MHz or 24MHz; usually commented out

SYS_CLK=24MHz

Parameter used to specify the CLK frequency; can be 24MHz or 48MHz; usually commented out

UTTX=PA05

Serial port (UART) TX

UTBD=1000000

Serial port baud rate

UTRX=PB01

Serial port upgrade; can be PB00, PB05 or PA05; usually commented out

RESET=PB01_08_0

Specifies the reset button pin and the reset parameters. The value to the right of the equals sign means port_long-press time_active level (the long-press time can be one of six values: 00, 01, 02, 04, 08 or 16, in seconds; when the long-press time is 00, the long-press reset function is disabled.)

EX_FLASH=PB07_2A_PB11

Specifies the external upgrade parameters used when the isd_download.exe tool programs an external flash:
The CS pin is PB07
Port C of SPI1 is used
If the norflash power supply is vddio, enter NULL; otherwise, enter the corresponding pin number
Must be used together with the packres.exe tool

EOFFSET=0

Do not change this arbitrarily. If you need to change it, contact a Jieli engineer. Note: this feature requires UBOOT support

AUTH_CODE=0

Disabled by default. To enable it, contact a Jieli engineer. Set this value according to the actual SDK

POWERON_TIMES=0

Duration of the chip's first power-on after programming is complete, in ms; at most 60S can be configured. Not set by default; supported only by AC695X, AC635N and AC6083 in version 2.27.2 and later. To enable it, contact a Jieli engineer

4.3.2.3. [TOOL_CONFIG] section options

Setting

Description

1TO2_MIN_VER=2.24.0

The minimum version of the 1-to-2 programmer that may load FW/UFW files generated from this configuration is 2.24.0. It must not be changed; if you need to change it, contact a Jieli engineer; this value is set according to the actual SDK

1TO8_MIN_VER=3.0.34

The minimum version of the 1-to-8 programmer that may load FW/UFW files generated from this configuration is 3.0.34. It must not be changed; if you need to change it, contact a Jieli engineer; this value is set according to the actual SDK

BTBOX_MIN_VER=1.2.4.f

The minimum version of the Bluetooth test box that may load UFW files generated from this configuration is 1.2.4.f. It must not be changed; if you need to change it, contact a Jieli engineer; this value is set according to the actual SDK

4.3.2.4. [CHIP_VERSION] section options

Setting

Description

SUPPORTED_LIST=A,B,C

Allows the FW/UFW generated from this configuration to be programmed into version A, B and C chips. It must not be changed; if you need to change it, contact a Jieli engineer. This value is set according to the actual SDK

4.3.2.5. [RESERVED_CONFIG] section options

  • This section configures the reserved areas and can exist on its own. The VM and PRCT areas are special: VM holds VM-related information, and PRCT holds information about the protected area.

  • If the [EXTRA_CFG_PARAM] section contains the RESERVED_OPT setting, no more than 6 entries can be configured in this section.

  • The VM, PROC and BIIF entries must have corresponding settings in a reserved configuration section (either [RESERVED_CONFIG] or [RESERVED_EXPAND_CONFIG]); otherwise, an error is reported.

  • Each entry follows the fixed format below:

Setting

Setting description

Value description

XXXX_ADR

Start address of the area; XXXX is the name of the reserved area

AUTO: the start address is allocated automatically by the tool (not supported for PROC and VM)
A numeric value means an absolute address
For VM, 0 means automatic allocation

XXXX_LEN

Length of the area; XXXX is the name of the reserved area

CODE_LEN: code length (PROC only)
A numeric value specifies the length

XXXX_OPT

Operation attribute of the area; XXXX is the name of the reserved area

0: erase the area when code is downloaded
1: leave the area untouched when code is downloaded
2: protect the area when code is downloaded

XXXX_FILE (optional)

When code is downloaded, the specified file is downloaded to the corresponding area; XXXX is the name of the reserved area


1. The name of the specified file (the file must be in the same directory as isd_download.exe)
2. To find this area, locate the corresponding reserved-area header by XXXX (the name of the reserved area), then get the location of the data from the address information in the header

4.3.2.6. [RESERVED_EXPAND_CONFIG] section options (optional)

  • This section is an extension of the [RESERVED_CONFIG] section. It is also used to configure reserved-area information, and its format follows the same rules as the entries in [RESERVED_CONFIG].

  • This section has no limit on the number of entries. If only the [RESERVED_EXPAND_CONFIG] section is configured and the [RESERVED_CONFIG] section is not, the RESERVED_OPT setting in the [EXTRA_CFG_PARAM] section has no effect.

  • This section can coexist with the [RESERVED_CONFIG] section. In that case, the RESERVED_OPT setting in the [EXTRA_CFG_PARAM] section still takes effect.
