6. Jieli Forced Upgrade Tool 4.0 User Guide

Preface

Thank you for using the Jieli Technology Forced Upgrade Tool 4.0!

Before using the tool, please read this manual carefully to ensure correct and safe use. After reading it, keep this manual in a safe place so that others can refer to it later.

If you encounter any problem that you cannot solve while using the tool, feel free to contact our engineers at any time. We will promptly provide you with the most effective service.

Note

1. In the default state, with no DIP switches turned on, the tool has no USB-related functions: no drive appears on the PC, and there is no serial printing, no serial upgrade, no JTAG function, etc. Like the 3.0 tool, it is purely an upgrade tool.

2. Only after DIP switch 7 is turned on and the tool is power-cycled does the tool have USB-related functions: serial printing, serial upgrade, a drive on the PC, viewing the user guide, JTAG debugging, etc. When the tool is power-cycled with switch 7 on and plugged into the PC, a drive with a pink ladybug icon appears on the PC. Double-click it to open it; it contains the instructions and the tools used, as shown in the figure Files on the drive.
