3.1. 测试盒简要介绍

3.1.1. 功能描述

杰理科技一拖二蓝牙测试盒主要用于杰理各系列蓝牙芯片设备的测试、升级。一拖二蓝牙测试盒主要有以下功能：

（1）蓝牙设备无线升级

（2）蓝牙设备有线升级

（3）蓝牙设备测试：包括通话测试、通话麦回路、BLE测试、快速测试、频偏测试、频偏自动校正等等

（4）蓝牙设备辅助测试

（5）其它功能配置和使用

  1. 通话测试

    使能该功能，测试盒会连接样机手机音频，然后可以进行通话测试，即对样机麦喊话，mic声音从测试盒喇叭出来

  2. 通话麦回路测试

    使能该功能，对样机麦喊话，音频传到测试盒,测试盒再传回到样机,样机喇叭播放出来

    ON : mic的声音从样机出来

    OFF: mic的声音从测试盒喇叭出来

Note

使用该功能拨码开关1需要为ON

  1. 快速测试

    使能该功能，连接上样机，测试盒会让样机进入快速测试模式，然后样机会开启扩音功能，对样机麦喊话，麦声音从喇叭出来，按样机上按键会播放一下按键音。

Note

该功能测试盒只负责发送启动命令，具体样机行为及流程由sdk支持

  1. 频偏测试

    使能该功能，连接上样机会进行频偏测试

  2. 频偏自动校正

Note

需同时开启频偏测试使能

  1. BLE测试

使能该功能后，可以测试BLE的频偏、自动校准、样机按下按键编号

Note

开启该功能后，只有频偏自动校正可以配置

3.1.5. 按键功能说明

  1. 复位按键

  2. B样机下一项测试,播歌测试—通话测试—断开连接（连接上样机双击为烧录认证码功能）

  3. A样机下一项测试,播歌测试—通话测试—断开连接（连接上样机双击为烧录认证码功能）

  4. 断开连接。长按此按键插入pc线，进入配置模式
