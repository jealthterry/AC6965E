6.3.2. Upper four DIP switches (several can be on at the same time)

  1. Whether the tool communicates with the PC is determined by DIP switch 7

    • Off: the tool cannot communicate with the PC, so none of the following operations work; the serial port cannot be used either.

    • Switch 7 on: the tool initializes its USB function, can act as a serial port tool and can receive commands from the PC.

  2. The default state of DP and DM on the tool's output is determined by DIP switch 5

    • Off: DP and DM on the tool's output are high-impedance by default.

    • Switch 5 on: DP and DM on the tool's output are used for the serial port function by default.

  3. When the tool receives a set-baud-rate command from the PC

Baud rate

Serial port

Description

1 or 111

Duplex mode

Duplex mode by default

2 or 112

Single-wire mode

TX used for both transmit and receive

3 or 113

Single-wire mode

TX used for both transmit and receive. In addition, when the baud rate is set to 9600 or less, TX sends uartkey. (Currently used for chips that support single-wire UART upgrade)

  1. When the tool receives a JTAG operation command from the PC: DP and DM on the tool's output are used for JTAG communication.

  2. When the tool receives an upgrade command from the PC: equivalent to pressing the upgrade button; the tool enters the upgrade process.

  3. When the tool receives a flash operation command from the PC: DP and DM on the tool's output are used for flash operations (they automatically return to the default state when the flash operation ends).
    The RX pin on the tool connects to the CS pin of the flash.
    DP on the tool's output connects to the CLK pin of the flash.
    The DM pin on the tool's output connects to both the DO and DO pins of the flash.
    RX --> CS
    DP --> CS
    DM --> DO
    DM --> DO

These pins are brought out on the tool's 10-pin JTAG connector:
TCK --> DP
TDO --> DM
TDI --> DM
TMS --> RX

Note

Also remember to supply 3.3V to the flash and to connect a common ground.

To operate on the on-chip flash of SH50, turn on DIP switch 6; the tool then enumerates as SH50 Burn v1.0.0.

  1. For the tool's own needs: switch 8 on means that after entering upgrade mode, the tool does not exit upgrade mode automatically.
