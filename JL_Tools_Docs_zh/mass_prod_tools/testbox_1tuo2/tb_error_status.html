3.13. 状态指示和报错提示说明

3.13.1. 状态指示

测试盒上电开机，测试，升级过程，LCD显示屏会对各个操作流程的状态进行显示，具体参考各个章节功能模块说明中的对应的LCD显示屏相关图片。

3.13.2. 报错提示说明

测试盒在进行测试盒升级过程，可能以为某种原因而出现测试、升级失败，LCD显示屏会对测试、升级等流程出现的异常进行报错提示。
