1. Development Environment Installation

1.1. Windows environment

By default, SDK projects support development with Code::Blocks on Windows.

Setting up the environment involves three main steps:

  1. Download and install Code::Blocks for Windows (click here to download)

  2. Open the installed Code::Blocks, then close it (this lets Code::Blocks generate some basic settings information)

  3. Download and install the latest Jieli toolchain for Windows (click here to download)

You can now open Code::Blocks projects to build and develop. For details, see Building and Downloading the SDK.

Note

The first time you build with Code::Blocks, a Security Warning dialog may pop up. For the solution, see Security Warning During Build and "Cannot Find @xxx.objs.txt" During Linking.

For other common issues, see:

  • Code::Blocks Usage and Troubleshooting

  • Common Issues and Solutions

  • Other Common Issues and Solutions

1.2. Linux environment

Currently, SDK projects support development and building with a Makefile on Linux by default; see Building with make.

  • Once the SDK post-processing script download.sh has been modified (based on the corresponding Windows script download.bat), it can generate .fw firmware files.

  • Downloading firmware to the device is not supported.

For the download links of the toolchain and the download directory post-processing tools, see Latest Tool Versions
