Preface

Thank you sincerely for using the Jieli Technology 1-to-2 programmer!

Before using the tool, please read this manual carefully to ensure correct and safe use. After reading it, keep this manual in a safe place so that others can refer to it later.

If you encounter any problem that you cannot solve while using the tool, feel free to contact our engineers at any time. We will promptly provide you with the most effective service.
