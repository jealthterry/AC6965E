7.4. KEY错误或不匹配

在一拖八烧录过程中出现“KEY错误或者不匹配”，可以尝试以下方法：

  1. 使用烧录器空片校验确认芯片是否是空片

  2. 空片情况下烧录出错，可以检查芯片VBAT电压与所需烧录电压是否相符(不同芯片烧录电压说明)

  3. 非空片情况下出错，请检查添加的key文件是否正确
