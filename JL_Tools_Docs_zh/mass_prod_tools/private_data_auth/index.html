5. 私有数据授权使用说明

私有数据授权是指将私有授权数据写入到FLASH特定区域中，以完成对私有算法授权的行为。

私有数据可以通过以下方式写入芯片FLASH中：

  1. 在样机中运行特定固件， 特定固件通过特定的SDK的接口写入。

  2. 使用RPC版本的烧录器，通过RPC接口将私有数据写入。

注意：必须通过SDK接口或者PRC接口将私有数据写入FLASH

在这种使用场景下，有两种角色：

  1. 算法提供商：提供算法库，并负责将私有数据写入芯片FLASH中。

  2. 方案商：方案具体开发者，将所有算法提供商的算法集成到方案中。

如果您使用的SDK不支持私有数据授权，那么请联系杰理科技获取相关补丁，并参照以下说明修改SDK。
