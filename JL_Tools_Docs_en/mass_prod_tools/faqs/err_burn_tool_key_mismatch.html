7.1. Firmware File KEY Does Not Match the Programmer KEY

When you deploy a file to a 1-to-2 programmer or a 1-to-8 programmer, the tool reports an error similar to the following:

The firmware file contains a KEY, and the programmer also contains a KEY (the programmer's KEY is fixed at the factory and bound to the distributor; users cannot change it). If the two do not match, an error is reported.

The main causes of this error are:

  1. The -key parameter was not specified when the firmware file was generated, so the generated firmware file has no KEY. Solution: in the download directory, modify the script that generates the firmware file to specify the parameter -key keyfile.key, where keyfile.key is the KEY file obtained from Jieli. As shown below:

Note

  1. If your KEY file name contains spaces, it is recommended to remove them, or to enclose the name in double quotes "", for example "key file with space.key".

  2. To avoid problems caused by mistyped file names, the key file name should not contain spaces, Chinese characters, etc.; use only English letters and digits.

  1. The wrong KEY file was specified when the firmware file was generated. For details, consult your distributor or Jieli.

  2. The current programmer may not support programming the corresponding chip. For details, consult your distributor or Jieli.
