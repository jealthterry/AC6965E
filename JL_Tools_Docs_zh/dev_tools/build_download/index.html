2. SDK 编译以及下载

在安装好工具链后，即可开始进行编译。

默认情况下，SDK 支持在 Windows 系统下进行编译以及下载。在 Linux 系统上，仅支持编译。

SDK 发布的时候，默认发布了 .cbp 后缀的 Code::Blocks 工程。此外，还同时发布了 Makefile 以及 VSCode 的配置。用户可以自行选择使用命令行进行编译。
